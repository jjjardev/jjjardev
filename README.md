## What I'm working on

### [HiliSenti](https://github.com/jjjardev/hilisenti) — First sentiment dataset for Hiligaynon  
[![Hugging Face Dataset](https://img.shields.io/badge/🤗%20Dataset-HiliSenti--v1-yellow)](https://huggingface.co/datasets/jjjardev/hilisenti-v1)
[![DOI](https://img.shields.io/badge/DOI-10.57967%2Fhf%2F8737-blue)](https://doi.org/10.57967/hf/8737)
[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/Data%20License-CC%20BY--NC--SA%204.0-lightgrey)](https://creativecommons.org/licenses/by-nc-sa/4.0/)
[![Code License: MIT](https://img.shields.io/badge/Code%20License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

- **23,337** real‑world Hiligaynon sentences with sentiment labels (Negative, Neutral, Positive)  
- Multi‑domain corpus: news, social media, translated reviews, and synthetic data  
- Fine‑tuned **XLM‑RoBERTa‑large** baseline achieving **93.5% accuracy** and **93.4% macro F1**  
- Entire pipeline built on **free Colab** and **free Drive**, no paid APIs or cloud credits  
- Dataset released on Hugging Face with permanent DOI; training code open‑source

I'm currently writing the academic paper (targeting ACL) and plan to release the fine‑tuned model adapter soon.

## How I work

I care about **resource‑efficiency**, **reproducibility**, and **building things that fill real gaps**.  
I believe good software and good research shouldn't require expensive infrastructure, so I push free tools as far as they'll go.  
My training pipeline survived Google Drive's 15 GB limit through a manual checkpoint‑pruning workflow I designed — unconventional, but it shipped a SOTA model for a language with no prior sentiment resources.
