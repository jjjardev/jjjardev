## About Me

I'm a BSIT graduate from Negros Occidental, Philippines, building language technology for low-resource languages and making AI work on hardware with just 1.5 GB free RAM and no GPU.

- Built the first sentiment dataset for Hiligaynon (23,000+ sentences, 93.5% accuracy)
- Created a sub-2B LLM orchestration system that runs on edge hardware with neuro-symbolic validation
- arXiv submission in progress for HiliSenti
- I document what didn't work, not just the successes

**2025 Focus:** Low-resource NLP pipelines for more Visayan languages and refining the edge orchestration validator.

## Featured Projects

### HiliSenti – First sentiment dataset for Hiligaynon
[![HF Dataset](https://img.shields.io/badge/🤗%20Dataset-HiliSenti--v1-yellow)](https://huggingface.co/datasets/jjjardev/hilisenti-v1)
[![DOI](https://img.shields.io/badge/DOI-10.57967%2Fhf%2F8737-blue)](https://doi.org/10.57967/hf/8737)

- 23,337 sentences, 3 classes. XLM-RoBERTa-large achieves 93.5% accuracy and 93.4% macro F1.
- Multi-domain corpus: news, social media, translated reviews, and synthetic edge cases.
- Built on free Colab and Google Drive. Dataset hosted on Hugging Face with permanent DOI.
- arXiv paper in preparation.

### edge-llm-orchestration – LLM orchestration under hard edge constraints
- Sub-2B models (`qwen2.5:1.5b`, `LiquidAI/lfm2.5-1.2b-instruct`) via Ollama.
- i3-1305U + 1.5 GB free RAM + no cloud. Single-file Python CLI with 4 modes.
- Neuro-symbolic per-slot scope-locked validator with empirical v0→v3 failure taxonomy.
- [Reflection docs](https://github.com/jjjardev/edge-llm-orchestration/blob/main/docs/reflection.md) cover what didn't work and why.
